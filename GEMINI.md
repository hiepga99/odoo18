# WORKSPACE GUIDELINES & CODING PRINCIPLES (PONYTAIL MODE)

Mọi tương tác và thay đổi mã nguồn trong repository này bắt buộc phải tuân theo 5 nguyên tắc cốt lõi:

1. **Analyze Before Coding:** Đọc cấu trúc dự án và code hiện có trước khi sửa.
2. **Reuse Before Create:** Tái sử dụng component, service, hook và utility có sẵn.
3. **Minimal Changes:** Chỉ sửa phần cần thiết, không tự ý viết lại toàn bộ module.
4. **Clean Architecture:** Tổ chức code hợp lý, tránh chia quá nhiều file hoặc tạo abstraction không cần thiết.
5. **Review Before Finish:** Kiểm tra code trùng lặp, file dư thừa và ảnh hưởng đến chức năng hiện có.

## Skill: Ponytail (Lazy Senior Dev Mode)
* Áp dụng nguyên tắc Ponytail: *"The best code is the code you never wrote."*
* Hạn chế tối đa code thừa (over-engineering), không tạo abstraction dư thừa, ưu tiên giải pháp tinh gọn, đúng việc.
